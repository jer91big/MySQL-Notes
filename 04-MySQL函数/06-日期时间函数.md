日期时间函数是档案室里的“时光钟表匠”：帮我们看现在几点、从时间戳里拆出年月日，或者把日期往前/往后拨几天。它们几乎出现在每一张带 `created_at`、`updated_at` 的业务表里。

函数总览见 [[01-SQL函数目录索引]]，上一篇是 [[05-数值函数]]。

### 1. 抓当前时间：`NOW()`、`CURDATE()`、`CURTIME()`

- **`NOW()`**：抓拍此刻完整的“日期 + 时间”（如 `2026-11-27 15:01:00`）。
- **`CURDATE()`**（部分方言也可写 `CURRENT_DATE`）：只要今天的**日期**，不含时分秒。
- **`CURTIME()`**：只要现在的**时间**。

```sql
SELECT
  NOW() AS 此刻,
  CURDATE() AS 今天,
  CURTIME() AS 现在时间;
```

### 2. 拆解年月日与格式化：`YEAR`、`MONTH`、`DAY`、`DATE_FORMAT`

像用放大镜从一串时间戳里单独挑出年份、月份或几号，方便按月统计报表：

- **`YEAR(dt)`、`MONTH(dt)`、`DAY(dt)`**：分别取年、月、日。
- **`HOUR(dt)`、`MINUTE(dt)`、`SECOND(dt)`**：分别取时、分、秒。
- **`DATE_FORMAT(dt, 格式)`**（MySQL）：按指定模板把日期印成好看的样式。

常用格式占位符：

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `%Y` | 四位年份 | `2026` |
| `%m` | 两位月份 | `11` |
| `%d` | 两位日期 | `27` |
| `%H` | 24 小时制小时 | `15` |
| `%i` | 分钟 | `01` |
| `%s` | 秒 | `00` |

```sql
SELECT
  created_at,
  YEAR(created_at) AS order_year,
  MONTH(created_at) AS order_month,
  DATE_FORMAT(created_at, '%Y-%m-%d %H:%i') AS formatted
FROM orders;
```

> 反向操作：把字符串解析成日期用 `STR_TO_DATE('2026-11-27', '%Y-%m-%d')`，可以理解为 `DATE_FORMAT` 的逆运算。

### 3. 时间加减与算间隔：`DATE_ADD`、`DATE_SUB`、`DATEDIFF`

- **`DATE_ADD(dt, INTERVAL n UNIT)`**：像拨动日历指针，往后推 `n` 天/月/年/小时，例如 `INTERVAL 7 DAY`、`INTERVAL 1 MONTH`。
- **`DATE_SUB(dt, INTERVAL n UNIT)`**：往前拨。
- **`DATEDIFF(d1, d2)`**（MySQL）：返回 `d1` 减 `d2` 的**天数差**，常用于算订单逾期几天、会员还剩多少天到期。

```sql
SELECT
  order_id,
  created_at,
  DATE_ADD(created_at, INTERVAL 30 DAY) AS due_date,
  DATE_SUB(created_at, INTERVAL 7 DAY) AS week_before,
  DATEDIFF(CURDATE(), DATE(created_at)) AS days_passed
FROM orders;
```

> 想算小时、分钟级的间隔，用 `TIMESTAMPDIFF(HOUR, start_time, end_time)`；`DATEDIFF` 只按“天”算。

### 4. 实战提醒：别让函数挡住索引

`WHERE YEAR(created_at) = 2026` 虽然好懂，但把函数包在索引列上，通常会让索引失效。数据量大时，改写成**区间范围**往往更友好：

```sql
-- 不推荐：索引列被函数包住
SELECT * FROM orders WHERE YEAR(created_at) = 2026;

-- 推荐：让 created_at 直接参与比较，索引用得上
SELECT * FROM orders
WHERE created_at >= '2026-01-01'
  AND created_at <  '2027-01-01';
```

这条规则对 `DATE_FORMAT`、`MONTH`、`DATE` 等包在列上的函数同样适用：**尽量把函数放在常量那一侧，而不是列这一侧。**
