数值函数是**逐行加工**：每一行数字进去，出来一个加工后的数字。它们常出现在 `SELECT` 的计算列、`WHERE` 条件、`ORDER BY` 排序里，也可以和聚合函数、`CASE WHEN` 组合使用。

函数总览见 [[01-SQL函数目录索引]]，上一台机器是 [[04-流程函数]]。

### 1. 四舍五入与截断：`ROUND`、`TRUNCATE`、`CEIL`、`FLOOR`

档案室里处理金额、折扣、测量误差时，光靠加减乘除还不够，得请出几位数学小工匠：

- **`ROUND(x, d)`**：把 `x` 四舍五入保留 `d` 位小数（`d` 省略或为 `0` 时取整）。像给数字装上弹簧秤，超过一半往上弹，不到一半往下沉。
- **`TRUNCATE(x, d)`**（MySQL 常见，不同数据库写法略有差异）：不讲情面，直接“一刀切”砍掉 `d` 位小数后面的尾巴，**不进位**。
- **`CEIL(x)` / `CEILING(x)`**：天花板向上取整。
- **`FLOOR(x)`**：地板向下取整。

比如算需要多少辆车运 `11` 个人（每车限坐 `4` 人）：`11 / 4 = 2.75`，`CEIL(2.75)` 直接顶到 `3` 辆车才够坐；`FLOOR(2.75)` 则只给 `2` 辆，会落下 3 个人。

| 函数 | `x = 2.756` 时 | 说明 |
| --- | --- | --- |
| `ROUND(x, 2)` | `2.76` | 四舍五入 |
| `TRUNCATE(x, 2)` | `2.75` | 直接截断 |
| `CEIL(x)` | `3` | 向上取整 |
| `FLOOR(x)` | `2` | 向下取整 |

### 2. 绝对值与取模：`ABS`、`MOD`

- **`ABS(x)`**：把负数变成正数，比如算温差或偏差 `ABS(实际值 - 预测值)`，结果永远非负。
- **`MOD(a, b)`**（也可以写 `a % b`）：算 `a` 除以 `b` 的**余数**。像发扑克牌一轮轮分到最后剩下的几张，常用来判断奇偶（`MOD(id, 2) = 0`）或做周期轮换。

### 3. 幂运算与随机数：`POWER`、`SQRT`、`RAND`

- **`POWER(x, y)` / `POW(x, y)`**：算 `x` 的 `y` 次方。
- **`SQRT(x)`**：算平方根。
- **`RAND()`**：摇出一个 `0`（含）到 `1`（不含）之间的随机小数，像管理员随手抛出一颗隐形骰子。

想抽 `1` 到 `10` 之间的随机整数，可以配合取整：

```sql
SELECT FLOOR(1 + RAND() * 10) AS random_num;
```

### 4. 组合示例

```sql
SELECT
  price,
  ROUND(price * 0.855, 2) AS round_price,
  TRUNCATE(price * 0.855, 2) AS trunc_price,
  ABS(price - 100) AS diff_from_100,
  MOD(id, 2) AS parity_flag
FROM products;
```

**动画画面**：每一行商品价格被送进流水线，先乘折扣，再分别经过 `ROUND` 的弹簧秤和 `TRUNCATE` 的铡刀，最后贴上“离 100 元差多少”和“奇偶编号”的标签。

### 5. 小提醒

- **`TRUNCATE(x, d)` 是数值函数，`TRUNCATE TABLE` 是清空整张表的 DDL 语句**，名字一样但完全不是一回事，别混淆。
- 金额、余额这类要求精确的计算，底层列仍应使用 `DECIMAL`；`ROUND` 更适合做展示层的最后加工。
- `ORDER BY RAND()` 可以随机排序，但大表上会全表排序、很慢，数据量大时不要用它做随机抽样。
