流程函数用于在查询结果里做**条件判断和空值兜底**：它不像 `WHERE` 那样把整行过滤掉，而是根据条件给每一行算出不同的值。`CASE WHEN` 是最常用的一种，可以放在 `SELECT`、`ORDER BY` 等位置。

查询基础见 [[01-SELECT查询]]。

### 1. `CASE WHEN`：查询里的“岔路口分流器”

有时候我们不想把数据过滤掉，而是想在查出来的每一行里，**按条件贴上不同等级或打分规则**。`CASE WHEN` 就像铁道上的**道岔**，从上到下遇到第一个满足的 `WHEN` 就拐过去，都不满足就走 `ELSE`：

```sql
SELECT
  name,
  score,
  CASE
    WHEN score IS NULL THEN '缺考/未录入'
    WHEN score >= 90 THEN '优秀'
    WHEN score >= 60 THEN '及格'
    ELSE '不及格'
  END AS 等级
FROM students;
```

**动画画面**：每一行学生数据开到 `CASE` 道岔前，先看是不是 `NULL`；不是再看是否 `>= 90`；不是再看是否 `>= 60`；全都不中就走 `ELSE` 兜底。最后必须用 `END` 把道岔收尾，并通常配上一个 `AS 等级` 别名。

小提醒：

- `CASE WHEN` 按**从上到下**的顺序判断，第一个满足的条件生效，所以条件要从特殊到一般排列。
- 如果省略 `ELSE`，所有条件都不满足时会返回 `NULL`。

### 2. `IF(条件, 成立值, 不成立值)`：二选一开关

`IF` 像只有两条路的电闸：条件为真走左边，条件为假走右边。适合规则简单、只有两种结果的场景。

```sql
SELECT
  name,
  score,
  IF(score >= 60, '通过', '补考') AS status
FROM students;
```

**小提醒：`NULL` 在条件里会被当作“不成立”。** 如果 `score` 是 `NULL`，`score >= 60` 的结果是“未知”，`IF` 会走“不成立”分支，于是缺考的同学会被标成“补考”。想区分缺考，可以写：

```sql
SELECT
  name,
  score,
  IF(score IS NULL, '缺考', IF(score >= 60, '通过', '补考')) AS status
FROM students;
```

规则一多，嵌套 `IF` 就会难读，这时换回 `CASE WHEN` 更清晰。

接下来三个函数更偏“空值处理”，但常和条件判断一起出现，所以放在同一篇里。

### 3. `IFNULL(表达式, 兜底值)`：单格空缺补丁

只盯第一个参数：是 `NULL` 就换成兜底值，不是 `NULL` 就原样放行。

```sql
SELECT
  name,
  IFNULL(nickname, '暂无昵称') AS display_name
FROM students;
```

**动画画面**：`nickname` 格子一打开如果是空的，`IFNULL` 马上塞一张 `'暂无昵称'` 贴纸补上，免得后面拼接或展示时出现空白。

`IFNULL` 是 MySQL 方言；标准 SQL / PostgreSQL 等更常用 `COALESCE(a, b)` 来替代它。

### 4. `COALESCE(值1, 值2, ...)`：多级备胎接力赛

从左到右挨个检查，**返回第一个不是 `NULL` 的值**；如果全都是 `NULL`，才返回 `NULL`。常用来做“优先取手机号，没有就取备用电话，还没有就显示无联系方式”。

```sql
SELECT
  user_id,
  COALESCE(mobile_phone, home_phone, emergency_phone, '无联系方式') AS contact
FROM users;
```

**动画画面**：第一棒 `mobile_phone` 掉棒（`NULL`），第二棒 `home_phone` 接上，还掉棒就第三棒顶上，谁第一个稳稳拿到接力棒，就交出谁。

### 5. `NULLIF(expr1, expr2)`：相等就抹成 `NULL` 的“消消乐”

如果 `expr1 = expr2`，返回 `NULL`；否则返回 `expr1`。它最实用的两个场景：

1. **防止除数为 0**：`sales / NULLIF(target, 0)`。当 `target` 是 `0` 时，`NULLIF` 把它变成 `NULL`，而 MySQL 里任何数除以 `NULL` 得到 `NULL`，不会直接报除零错误；之后还能用 `COALESCE(..., 0)` 兜底成 `0`。
2. **把空字符串清洗成 `NULL`**：`NULLIF(TRIM(remark), '')`。

```sql
SELECT
  dept_name,
  completed_tasks,
  target_tasks,
  COALESCE(completed_tasks / NULLIF(target_tasks, 0), 0) AS completion_rate
FROM departments;
```

### 6. 一张表看懂这几位“流程 / 空值小助手”

| 函数 | 核心动作 | 典型用途 |
| --- | --- | --- |
| `CASE WHEN ... END` | 多分支判断，从上到下第一个命中的生效 | 分等级、多条件映射 |
| `IF(cond, t, f)` | 条件真取 `t`，假取 `f` | 简单二选一标签 |
| `IFNULL(a, b)` | `a` 为 `NULL` 则取 `b` | 单列空值填默认值（MySQL 方言） |
| `COALESCE(a, b, c...)` | 返回第一个非 `NULL` 值 | 多级备选字段 / 最终兜底 |
| `NULLIF(a, b)` | `a` 等于 `b` 返回 `NULL`，否则返回 `a` | 规避除零、把空串转 `NULL` |

> **记忆顺序**：`CASE` 管多岔路，`IF` 管二选一，`IFNULL` 管单格补洞，`COALESCE` 管多级备胎，`NULLIF` 管“相等就抹空”。
