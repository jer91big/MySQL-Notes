MySQL 中添加和删除约束，主要使用 **ALTER TABLE（修改表结构）**。

你前面学过 `CREATE TABLE`、`DROP TABLE`、`ADD COLUMN` 等语句，这次只需要在它们的基础上增加几个新语法。

# **一、添加约束（ADD）**

基本语法：

```
ALTER TABLE 表名
ADD CONSTRAINT 约束名称 约束类型 (字段名);
```

其中：

- `ALTER TABLE`：修改表结构。
    
- `ADD CONSTRAINT`：添加约束。
    
- `约束名称`：自己起的名字。
    
- `约束类型`：PRIMARY KEY、UNIQUE、FOREIGN KEY 等。
    

## **1. 添加主键约束（PRIMARY KEY）**

```
ALTER TABLE student
ADD CONSTRAINT pk_student
PRIMARY KEY (id);z
```

给 student 表的 id 字段添加主键约束。

也可以简写：

```
ALTER TABLE student
ADD PRIMARY KEY (id);
```

## **2. 添加唯一约束（UNIQUE）**

```
ALTER TABLE student
ADD CONSTRAINT uk_phone
UNIQUE (phone);
```

给 phone 字段添加唯一约束。

也可以简写：

```
ALTER TABLE student
ADD UNIQUE (phone);
```

## **3. 添加非空约束（NOT NULL）**

非空约束的添加方式和上面略有不同，使用 `MODIFY COLUMN`：

```
ALTER TABLE student
MODIFY COLUMN name VARCHAR(20) NOT NULL;
```

表示修改 name 字段，使其不允许为 NULL。

注意：这里要保留原来的数据类型以及其他需要保留的列属性。

## **4. 添加默认约束（DEFAULT）**

```
ALTER TABLE student
ALTER COLUMN status SET DEFAULT '正常';
```

给 status 字段设置默认值为正常。

## **5. 添加检查约束（CHECK）**

```
ALTER TABLE student
ADD CONSTRAINT chk_age
CHECK (age >= 18);
```

要求 age 必须大于等于 18。

## **6. 添加外键约束（FOREIGN KEY）**

```
ALTER TABLE student
ADD CONSTRAINT fk_class
FOREIGN KEY (class_id)
REFERENCES class(id);
```

表示 student 表的 class_id 引用 class 表的 id。

# **二、删除约束（DROP）**

删除约束也使用 `ALTER TABLE`，但不同约束的删除语法略有区别。

## **1. 删除主键约束**

```
ALTER TABLE student
DROP PRIMARY KEY;
```

## **2. 删除唯一约束**

```
ALTER TABLE student
DROP INDEX uk_phone;
```

这里的 `uk_phone` 是之前创建唯一约束时指定的名称。

如果没有指定名称，可以先使用：

```
SHOW INDEX FROM student;
```

查看索引名称。

## **3. 删除非空约束**

使用 `MODIFY COLUMN`，将字段改回允许 NULL：

```
ALTER TABLE student
MODIFY COLUMN name VARCHAR(20) NULL;
```

## **4. 删除默认约束**

```
ALTER TABLE student
ALTER COLUMN status DROP DEFAULT;
```

## **5. 删除检查约束**

```
ALTER TABLE student
DROP CHECK chk_age;
```

## **6. 删除外键约束**

```
ALTER TABLE student
DROP FOREIGN KEY fk_class;
```

# **三、添加和删除约束语法汇总**

这张表建议直接放进你的 MySQL 笔记。

|约束类型|添加语法|删除语法|
|---|---|---|
|主键|`ADD PRIMARY KEY (id)`|`DROP PRIMARY KEY`|
|唯一|`ADD UNIQUE (phone)`|`DROP INDEX 约束名`|
|非空|`MODIFY COLUMN name 类型 NOT NULL`|`MODIFY COLUMN name 类型 NULL`|
|默认|`SET DEFAULT 值`|`DROP DEFAULT`|
|检查|`ADD CONSTRAINT 名称 CHECK (条件)`|`DROP CHECK 约束名`|
|外键|`ADD CONSTRAINT 名称 FOREIGN KEY...`|`DROP FOREIGN KEY 约束名`|

# **四、几个容易混淆的地方**

**1. 为什么有些约束需要名称？**

例如：

```
ALTER TABLE student
ADD CONSTRAINT uk_phone UNIQUE (phone);
```

这里 `uk_phone` 就是约束名称，方便以后删除和管理。

通常命名习惯：

|前缀|含义|
|---|---|
|pk_|主键|
|uk_|唯一约束|
|fk_|外键|
|chk_|检查约束|

**2. 为什么删除唯一约束使用 DROP INDEX？**

因为 MySQL 中 UNIQUE 约束是通过唯一索引实现的，所以删除唯一约束通常使用 `DROP INDEX`。

**3. 删除约束之前需要注意什么？**

如果表中已经存在不符合新约束的数据，添加约束时可能失败。

例如：phone 中已经存在重复值，就不能直接添加 UNIQUE。
