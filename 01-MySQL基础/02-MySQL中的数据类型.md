MySQL 中的数据类型非常丰富，主要可以分为四大核心大类：**数值类型**、**日期和时间类型**、**字符串类型**以及 **JSON 类型**。合理选择数据类型不仅能节省存储空间，还能极大地提升查询性能。

### 1. 数值类型 (Numeric Types)

数值类型主要分为整数、浮点数和定点数。每个整数类型还可以选择是有符号（`SIGNED`，默认，可以存负数）还是无符号（`UNSIGNED`，只能存非负数，但上限翻倍）。


- **整数类型**：
    
    - `TINYINT`：1 个字节（-128 ~ 127）
        
    - `SMALLINT`：2 个字节

    - `MEDIUMINT`：3 个字节
       
    - `INT` (或 `INTEGER`)：4 个字节，最常用的整数类型。
        
    - `BIGINT`：8 个字节，常用于自增 ID（如用户表主键）。
        
- **浮点数类型**（存在精度损失风险）：
    
    - `FLOAT`：单精度浮点数（4 字节）
        
    - `DOUBLE`：双精度浮点数（8 字节）
        
- **定点数类型**（高精度，常用于财务）：
    
    - `DECIMAL(M, D)`：M 是总位数，D 是小数位数。例如 `DECIMAL(10, 2)` 最大可以存 `99999999.99`，不会产生浮点数计算误差。
       

### 2. 日期和时间类型 (Date and Time Types)

用来存储时间、日期或时间戳。

- `DATE`：仅日期，格式为 `YYYY-MM-DD`（如 `2026-06-06`）。
    
- `TIME`：仅时间或持续时间，格式为 `HH:MM:SS`。
    
- `DATETIME`：日期和时间，格式为 `YYYY-MM-DD HH:MM:SS`，不受时区影响。
    
- `TIMESTAMP`：时间戳，格式与 `DATETIME` 类似，但它会随着服务器时区的变化而自动转换，常用于记录数据的“最后修改时间”。
    
- `YEAR`：年份，格式为 `YYYY`。
    

### 3. 字符串类型 (String Types)

用于存储文本数据，其中最经典的对比是 `CHAR` 和 `VARCHAR`。


- **定长与变长字符串**：
    
    - `CHAR(M)`：**定长**字符串。不管实际存的内容有多长，都会占用固定的 M 个字符空间（空间换时间）。
        
    - `VARCHAR(M)`：**变长**字符串。根据实际内容的长度动态占用空间，最大长度由 M 决定（时间换空间）。
        
- **文本大对象 (Text)**：
    
    - `TINYTEXT`, `TEXT`, `MEDIUMTEXT`, `LONGTEXT`：用于存储大段文本文章，无需指定长度 M。
        
- **二进制大对象 (Blob)**：
    
    - `TINYBLOB`, `BLOB`, `MEDIUMBLOB`, `LONGBLOB`：用于存储图片、音频等二进制数据（但在实际开发中，通常只存文件的路径或 URL，很少直接把大二进制存进数据库）。
        
     
- **特殊选择类型**：
    
    - `ENUM`：枚举类型，只能从预设的列表中选择**一个**值（如 `ENUM('男', '女', '保密')`）。
        
    - `SET`：集合类型，可以从预设的列表中选择**多个**值。
    
### 4. JSON 类型 (JSON Type)

从 MySQL 5.7.8 开始引入。

- `JSON`：用于高效存储和查询 JSON 格式的数据。它自带格式验证，并且支持对 JSON 内部的键值进行索引和查询，非常适合处理半结构化数据。

### 💡 核心数据类型速查与选型建议

|**类型分类**|**常用类型**|**典型应用场景**|
|---|---|---|
|**整数**|`INT`, `BIGINT`|主键 ID、年龄、数量统计|
|**高精度小数**|`DECIMAL`|价格、账户余额、订单金额|
|**字符串**|`VARCHAR`|姓名、邮箱、地址、标题等大多数文本|
|**时间**|`DATETIME`, `TIMESTAMP`|创建时间 `created_at`、更新时间 `updated_at`|
|**大文本**|`TEXT`|文章正文、评论内容、日志|

选好类型后，这些列就可以在 [[03-MySQL 表的创建、删除与修改|建表]] 时使用，之后用 [[01-SELECT查询]] 查询数据。
